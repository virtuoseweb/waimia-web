# 03 — Stratégie de contenu & éditoriale

> ⚠️ Framing antérieur au positionnement V8 (2026-07-12). La mécanique (funnel/canaux/éditorial) reste valable ; le récit de marque canonique = `strategy/10 §0bis` + `docs/synthese-v1/SYNTHESE.md`.

> Source de vérité contenu pour Waimia. Aligné sur le silo « Site web IA »
> (`strategy/silo`, `strategy/site-final`), la recherche SEO/GEO gratuite
> (`strategy/recherche-seo-geo`) et le positionnement « zone blanche » (Limova ↔ ClaudIn).
> Cible : départements marketing PME/ETI · ancrage Montpellier/Occitanie · fondateur solo.
> Principe : **un praticien qui montre, pas un gourou qui promet.** Calibré pour tenir 90
> jours en solo, automation IA maximale via les skills `skills/`.

## 0. Cadre en une page
Objectif business : générer des leads pour le produit d'appel (audit quick win + **site web
intelligent dès 2 000 € HT**, Essentiel), nourrir l'escalade « Growth System IA », installer Waimia comme **entité
citable par les IA** (GEO) sur « site web IA pour PME ». Trois leviers, un moteur : SEO classique
+ **GEO** (citations ChatGPT/Claude/Perplexity, 3-6 mois) + **autorité-praticien** (LinkedIn n°1).
Avantage déloyal : Waimia **prouve par l'usage** (`waimia.com`, `virtuoseweb.fr` + vrais clients).
Règle : *l'IA produit le draft, l'humain garde la décision et la preuve.*

## 1. Piliers de contenu (tout contenu appartient à UN pilier)
1. **Site web IA-native** (cœur silo, commercial, ~40 %) : Astro vs WordPress, refonte, perf/coût
   réels, éditable par IA, prêt GEO. Convertit. → silo `/offres/site-web-ia` + **cluster d'articles
   in-silo** (seul silo SEO ; les prestations Acquérir sont des **sections ancrées** du pilier
   vitrine Growth System IA, pas des pages enfants — `strategy/02 §0bis`).
2. **GEO & visibilité IA** (informationnel, signature, ~25 %) : se faire citer par les IA,
   cohérence d'entité, Schema.org, GEO vs SEO. Installe l'expertise.
3. **Marketing augmenté par l'IA** (escalade, ~20 %) : content automation, tunnel IA, ads ROI,
   agent IA prospection/relance (« salarié virtuel » à l'usage). Pont vers les offres hautes.
4. **Ancrage local Montpellier / praticien** (E-E-A-T, conversion rapide, ~15 %) : création site
   Montpellier, cas locaux, coulisses solo. Convertit le plus vite sur domaine neuf.

> Local + GEO sous-représentés en volume mais **surpondérés en priorité de lancement** (quick wins).

## 2. Ligne éditoriale & ton — praticien, pas prédicateur
Sept règles non négociables : (1) **preuve avant affirmation** (chiffre/source datée/cas réel) ;
(2) **anti-théâtre** (zéro hype/« révolution ») ; (3) **pas de flatterie** ; (4) **tranchant mais
honnête** (on prend position, on assume l'incertitude) ; (5) **concret > conceptuel** (quoi faire
lundi, combien, combien de temps) ; (6) **sobriété typo, zéro emoji** (« », espaces insécables) ;
(7) **« je » du praticien (LinkedIn/coulisses), « nous » de la marque (blog/newsletter)**.
On dit : « site IA-native », « éditable par IA », « audit quick win », « salarié virtuel »,
« piloté au ROI », « mesuré le [date] ». On évite : « solution innovante », « disruptif »,
« révolutionnaire », « expert n°1 ».

## 4. Formats & gabarits
- **Article pilier** (1 500-3 000 mots, `skills/article-add`) : H1 prestation, lede promesse+preuve,
  **H2 en questions** ouvrant sur **réponse directe 40-60 mots** (format citation IA), ≥3 sources
  datées, chiffres/cas réels, Schema.org `Article`, maillage interne auto, **1 CTA** net.
- **Comparatif/« vs »** : tableau critères, verdict assumé, cas limites honnêtes (très cité en GEO).
- **Cas client** (`Case`) : Contexte chiffré → Intervention → Résultats datés → Ce qu'on a appris.
  Validation client des chiffres avant publication.
- **Post LinkedIn** (`skills/post-linkedin`) : accroche qui dérange → 1 idée + 1 preuve → micro-récit
  → CTA léger. 0 emoji, ≤5 hashtags. Carrousel réservé aux contenus à étapes.
- **Newsletter** (`skills/newsletter-mensuelle`) : édito tranchant → veille IA (3-4 signaux) →
  2-3 articles → 1 cas → 1 CTA. Lecture 5 min. Envoi sur `sendNow=true` explicite.

## 5. Pipeline d'automation (80 % skill / 20 % décision humaine)
```
[1] PLANIFIER  skills/calendrier-editorial (1×/mois) → trous catégorie/cluster → 5-10 sujets
[2] DRAFTER    skills/article-add → MDX in-silo (H2-questions, Schema, sources, maillage)
[3] RELIRE     humain GF-1 (preuve réelle, ton, typo, CTA, exactitude cas)
[4] PUBLIER    commit src/content/blog/<slug>.mdx → build → prod (feat/<scope>, preview)
[5] DÉRIVER    skills/post-linkedin <slug> → 3 variantes
[6] DISTRIBUER LinkedIn perso 3×/sem. (seul canal social T1)
[7] AGRÉGER    skills/newsletter-mensuelle → veille-ia MDX → Resend
```
Contrôles humains (les seuls) : tri des sujets, relecture GF-1, validation chiffres client,
déclenchement envoi newsletter. Renfort ponctuel : plugin `marketing` (content-creation,
email-sequence, campaign-plan) pour nurturing/lancements. **Moteur = les 4 skills repo.**

## 6. Distribution & repurposing (1 article → N actifs)
**T1 (2 canaux) :** Article → post texte LinkedIn → carrousel (si étapes) → bloc newsletter →
extrait GEO (réponse 40-60 mots autonome) → recyclage trimestriel (MAJ date = signal SEO+GEO).
Script vidéo/podcast = **réserve, différée** jusqu'à ≥3 clients récurrents (C5).

**Pipeline interconnecté (chantier produit, cf `05 §3`) — DIFFÉRÉ jusqu'à ≥3 clients
récurrents** : quand un article est publié, le système enchaînera automatiquement → **script**
→ **podcast / vidéo YouTube** → dérivés sociaux → **transmission à Simon ou au responsable
marketing** pour validation. Pas activé au démarrage (T1 = LinkedIn + article). Le contenu n'est pas un
livrable isolé : c'est un **flux** alimenté depuis une seule source (le MDX du site IA augmenté).
**Cohérence d'entité** (nom/expertise/zone identiques sur site + LinkedIn + GBP + annuaires) :
chaque post renforce l'autorité que Perplexity/ChatGPT exploitent. La distribution **est** la moitié du GEO.

## 7. KPIs & boucle (domaine neuf + solo : signaux de traction, pas volumes d'agence)
**Primaires (paient le runway)** : 3-6 leads qualifiés / 2-4 audits / ≥1 conversion audit→site sur 90 j.
**Visibilité** : impressions LinkedIn croissantes ; +30-80 abonnés newsletter ; impressions GSC
silo dès S6-S8 ; présence requêtes locales mois 2-3 ; **1res citations IA à 3-6 mois** (test mensuel).
**Mesure GEO gratuite** : 1×/mois, requêtes test fixes à ChatGPT/Claude/Perplexity, loguer présence/
formulation/source. **Boucle GSC** : hebdo (10 min) repérer requêtes page 2-3 → enrichir l'article/
poster dessus ; trimestriel ajuster H1 + carte de sujets (volumes réels GSC > estimations `53`) ;
capitaliser les apprentissages dans les skills. *Hypothèse → ship → mesure → ajuste → capitalise.*

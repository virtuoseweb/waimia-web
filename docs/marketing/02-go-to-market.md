# 02 — Go-to-market & funnel

> Comment Waimia transforme un inconnu en client qui paie, puis en compte qui s'étend.
> Aligné `marketing/01-positionnement` (offre/pricing) + `04-acquisition-canaux` (canaux) +
> `03-content-editorial` (contenu) + `05-boilerplate-produit` (le produit vendu).

## 1. Stratégie « cheval de Troie » en 3 temps
1. **Porte d'entrée marketing tangible** — le **site web IA** (amélioré par agents visibles :
   chat de qualification, scoring lead, contenu, social) est le produit d'appel concret. Cible
   directe : départements/équipes marketing. Ils achètent quelque chose qu'ils **comprennent**.
2. **Révélation** — une fois qu'ils ont goûté la puissance sur leur terrain familier (le web/
   marketing), ils réalisent que l'IA n'est pas un gadget. Le site **démontre** par l'usage.
3. **Horizontalisation consulting** — audit des process + agents IA sur mesure sur d'autres
   départements (commercial, ops, support, RH, finance). **Le ticket monte.**

## 2. Funnel & parcours (de l'inconnu au compte étendu)
```
AWARENESS      LinkedIn perso + SEO/GEO + GBP local + bouche-à-oreille
   │           (contenu praticien, cas, comparatifs — cf 03/04)
   ▼
INTÉRÊT        visite site IA-native → preuve par l'usage (perf, agents visibles, cas)
   │           lead magnet : mini-audit / diagnostic
   ▼
CONSIDÉRATION  AUDIT QUICK WIN (produit d'appel n°0) → diagnostic concret + plan
   │           séquence email nurture (marketing:email-sequence)
   ▼
DÉCISION       SITE WEB IA dès 3 000 € HT (produit d'appel n°1, paliers)
   │           livraison rapide, prouvée → confiance installée
   ▼
EXPANSION      GROWTH SYSTEM IA → AGENTS À L'USAGE (autres départements)
               facturation à la valeur, compte qui s'étend
```

## 3. Conversion — les points de bascule
- **Visiteur → lead** : 1 CTA primaire par page (audit), agents visibles (chat qualif),
  formulaire court + Cal.com réel. Preuve sociale réelle (cas), pas de promesse creuse.
- **Lead → audit** : le mini-audit gratuit/léger lève le risque ; le rapport d'audit **montre**
  le concret (quick wins identifiés) et ouvre naturellement sur le site IA.
- **Audit → site** : le plan d'audit chiffre le gain ; le palier 3 000 € rend le « oui » facile.
- **Site → growth/agents** : une fois la confiance et les premiers résultats mesurés, l'audit
  process horizontal propose les agents là où le ROI est démontrable.

## 4. Plan 90 jours (lancement)
- **Mois 1** — fondations : site assaini + pilier + page locale Montpellier en ligne (`strategy/
  site-final`), GBP + LinkedIn activés, 4 contenus quick-win (`03`), lead magnet audit branché.
- **Mois 2** — traction : outbound ciblé PME locales (Vibe Prospecting, `04 §5`), séquences email,
  profondeur de contenu, 1ers audits réalisés.
- **Mois 3** — preuve : cas clients réels formalisés, 1res conversions site, revue GSC →
  ajustement H1/sujets, décision go/kill ads selon coût par RDV.

## 5. Objectifs (réalistes, domaine neuf + solo)
3-6 leads qualifiés · 2-4 audits réalisés · ≥1 signature site web IA · base newsletter +30-80 ·
1res citations IA amorcées (3-6 mois). Le but du trimestre : **prouver le funnel**, pas le scaler.

## 6. Pricing — logique d'escalade
Audit (appel) → Site 3 000 € HT (paliers) → Growth System IA (devis) → **agents à l'usage**
(actions/résultats, pas abonnement plat : l'entreprise paie l'agent comme un salarié). On
n'impose jamais l'escalade : on la déclenche **quand le ROII précédent est démontré**. Détail
offre/pricing : `marketing/01 §5`. Modèle produit (fork client, facturation usage) : `05`.

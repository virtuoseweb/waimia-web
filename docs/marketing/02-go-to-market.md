> Cadre marque (TRANCHÉ Simon 2026-06-14, réf `business/00-references`) : Waimia = **cabinet
> d'orchestration IA / conseil en transformation IA**, **PAS une agence web**. Le **site web
> intelligent = porte d'entrée tangible** (preuve, pas produit). Le funnel mène par le **système /
> résultat**, jamais par « un site ». Détail : `strategy/03 §7`.

## 1. Stratégie « cheval de Troie » en 3 temps
1. **Porte d'entrée tangible** — le **site web intelligent** (amélioré par agents visibles : chat de
   qualification, scoring lead, contenu, social) est le produit d'appel **concret et compréhensible**,
   souvent précédé d'un **diagnostic IA financé** (« Osez l'IA », ≤ 50 % financé → friction quasi
   nulle + posture conseil d'emblée). Le client achète quelque chose qu'il **voit** — mais on le
   vend comme la première brique d'un **système**, pas comme « un site ».
2. **Révélation** — une fois la puissance goûtée sur un terrain familier (le web/acquisition), il
   réalise que l'IA n'est pas un gadget. Le site **démontre par l'usage** que Waimia **orchestre**
   l'IA (au-dessus de la commodité Wix/Lovable) — d'où la légitimité à élargir.
3. **Horizontalisation consulting** — audit des process + agents IA sur mesure sur d'autres
   départements (commercial, ops, support, RH, finance). C'est là que le **cabinet** prend tout son
   sens : on conçoit le système qui fait tourner la PME à l'IA. **Le ticket monte.**

## 2. Funnel & parcours (de l'inconnu au compte étendu)
```
AWARENESS      LinkedIn perso + SEO/GEO + GBP local + bouche-à-oreille
   │           (contenu praticien, cas, comparatifs — cf 03/04)
   ▼
INTÉRÊT        visite site IA-native → preuve par l'usage (perf, agents visibles, cas)
   │           lead magnet : diagnostic IA (angle aides « Osez l'IA »)
   ▼
CONSIDÉRATION  DIAGNOSTIC / AUDIT IA (porte d'entrée) → diagnostic concret + plan
   │           angle financement « Osez l'IA » (≤ 50 %) · séquence email nurture
   ▼
DÉCISION       SITE WEB INTELLIGENT (porte d'entrée tangible, plancher 2 000 € HT)
   │           Essentiel 2 000 / Croissance 4 000 / Complet 7 000 / Intelligence 10 000 / Sur mesure
   │           livraison rapide, prouvée → confiance installée
   ▼
EXPANSION      GROWTH SYSTEM IA → AGENTS À L'USAGE (autres départements)
               facturation à la valeur, compte qui s'étend (le cabinet orchestre)
```

## 3. Conversion — les points de bascule
- **Visiteur → lead** : 1 CTA primaire par page (diagnostic IA), agents visibles (chat qualif),
  formulaire court + Cal.com réel. Preuve sociale réelle (cas), pas de promesse creuse.
- **Lead → diagnostic** : l'angle financement (« Osez l'IA », ≤ 50 %) lève le risque ; le rapport
  de diagnostic **montre** le concret (actions chiffrées) et ouvre naturellement sur le site intelligent.
- **Diagnostic → site** : le plan chiffre le gain ; le palier **Essentiel 2 000 €** rend le « oui »
  facile (plancher du modèle), avec montée Croissance/Complet/Intelligence selon le besoin.
- **Site → growth/agents** : une fois la confiance et les premiers résultats mesurés, l'audit
  process horizontal propose les agents là où le ROI est démontrable — le cabinet orchestre.

## 4. Plan 90 jours (lancement)
- **Mois 1** — fondations : site assaini + pilier + page locale Montpellier en ligne (`strategy/
  site-final`), GBP + LinkedIn activés, 4 contenus quick-win (`03`), lead magnet audit branché.
- **Mois 2** — traction : outbound ciblé PME locales (Vibe Prospecting, `04 §5`), séquences email,
  profondeur de contenu, 1ers audits réalisés.
- **Mois 3** — preuve : cas clients réels formalisés, 1res conversions site, revue GSC →
  ajustement H1/sujets, décision go/kill ads selon coût par RDV.

## 5. Objectifs (réalistes, domaine neuf + solo)
3-6 leads qualifiés · 2-4 audits réalisés · ≥1 signature site web IA · base newsletter +30-80 ·
1res citations IA amorcées (3-6 mois). Le but du trimestre : **prouver le funnel**, pas le scaler.

## 6. Pricing — logique d'escalade
Diagnostic IA (porte d'entrée, adossé aux aides « Osez l'IA ») → **Site web intelligent**
(Essentiel **2 000** / Croissance 4 000 / Complet 7 000 / Intelligence 10 000 / Sur mesure ;
**plancher 2 000 €**) → Growth System IA (devis) → **agents à l'usage** (actions/résultats, pas
abonnement plat : l'entreprise paie l'agent comme un salarié). On n'impose jamais l'escalade : on
la déclenche **quand le ROI précédent est démontré**. Référence canonique offre/pricing :
`business/00-references §Offer ladder` (cité aussi par `marketing/01 §5`). Modèle produit (fork
client, facturation usage) : `05`.

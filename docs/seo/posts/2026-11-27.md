## Plugin Make pour Claude : les autorisations à donner en PME

- Page : `/blog/plugin-make-claude`

---

Depuis hier, Claude peut créer, modifier et supprimer vos scénarios Make. Si vous le laissez faire.

Make a publié un plugin pour Claude. On décrit une tâche dans la conversation, Claude construit le scénario dans Make, le planifie et le lance. C'est pratique, et ça demande trois décisions avant d'ouvrir les droits.

Qui a le droit de construire. Avec les autorisations de gestion, Claude a accès à des outils qui suppriment un scénario ou vident un data store. Je les réserve à une seule personne, dans une équipe Make de test. Les autres n'ont que « Lancer vos scénarios ».

Combien ça consomme. Un déclencheur planifié coûte un crédit à chaque vérification, même quand il ne trouve rien. Un scénario qui surveille une boîte toutes les quinze minutes, c'est 96 crédits par jour avant le premier e-mail traité. Je demande toujours la fréquence avant d'activer.

Ce que veut dire « success ». Un statut vert dit que les modules ont tourné, pas que la bonne donnée est arrivée au bon endroit. Après chaque création, je fais relire le résultat dans l'outil de destination.

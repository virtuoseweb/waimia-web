## Fin des GPT personnalisés : reconstruire leurs actions avant le 11 décembre

Votre GPT appelle Make, n8n ou votre CRM avec une clé API ? Le 11 décembre, ce bout-là ne vous suivra pas.

OpenAI retire les GPT personnalisés le 11 décembre 2026. La migration vers un plugin reprend les consignes et les fichiers. Les actions, ces appels à vos outils, restent derrière.

Tout le monde le dit. Ce qu'on dit moins : une action protégée par une clé API n'a pas d'équivalent direct. Pour brancher un serveur MCP à ChatGPT, OpenAI propose OAuth ou aucune authentification. Pas de champ pour une clé.

Ce que je conseille, dans l'ordre :

Listez vos GPT qui ont des actions et notez, pour chacune, comment elle s'authentifie. C'est écrit dans l'éditeur, onglet Actions.

Si l'action déclenche un scénario Make ou un workflow n8n, passez par leur serveur MCP en OAuth. La clé de votre CRM reste dans l'outil où elle vit déjà.

Si elle appelle votre propre API, il faut un petit serveur MCP en OAuth devant. Commencez-le maintenant, pas la semaine du retrait.

Et ne mettez jamais la clé dans l'URL du serveur pour aller plus vite.

## Claude for Manufacturing : ce qu'il fait dans une PME industrielle, et ce qu'il demande

- Page : `/blog/claude-for-manufacturing-pme`
- Commit de contenu : à renseigner après le push (voir le calendrier, entrée `idee-claude-for-manufacturing-pme-industrielle`)
- Brouillon : à relire et à publier par Simon

Anthropic a sorti un plugin pour les usines. Avant de regarder les 17 compétences, regardez votre ERP.

Claude for Manufacturing se branche sur deux ERP : Oracle NetSuite et Infor M3. Si vous êtes sur Sage, Cegid, Divalto ou SAP, il n'y a pas de connecteur.

Ce n'est pas bloquant. La documentation du plugin dit que 11 de ses 12 compétences simples tournent avec un dossier de fichiers CSV. Le vrai sujet devient donc : votre ERP sait-il sortir un export propre chaque nuit, toujours au même nom ?

Deux points que je n'ai vus dans aucun article de lancement.
Le dépôt d'Anthropic présente le plugin comme une implémentation de référence, non maintenue. Il faut quelqu'un chez vous, ou chez votre prestataire, pour l'adapter et le garder à jour.
Et le connecteur Microsoft 365 cherche dans tout SharePoint avec les droits de l'utilisateur. Si vos tarifs fournisseurs sont ouverts à tout le monde, Claude les trouvera pour tout le monde.

Par où je commencerais : le rapport de production du matin. C'est le seul enchaînement du plugin sans étape de validation, il n'écrit dans aucun système, et il se compare ligne à ligne avec celui que fait votre chef d'équipe.

Mesurez d'abord le temps que prend ce rapport aujourd'hui. Ensuite seulement, testez.

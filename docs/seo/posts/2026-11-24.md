## Claude Ship : faut-il laisser Claude approuver vos pull requests ?

Anthropic vient de sortir un agent qui peut approuver le code de vos développeurs. La question n'est pas de savoir s'il est bon. C'est de savoir ce que votre configuration le laisse faire.

Claude Ship, lancé le 23 novembre, prend une pull request GitHub après son ouverture : un agent la relit, un autre corrige les tests qui cassent, un troisième décide qui doit encore l'approuver, d'après un fichier de règles écrit par votre équipe.

J'ai lu la documentation de ce troisième agent. Elle liste elle-même les cas où du code peut partir alors que seul son auteur l'a regardé : le contrôle n'est pas rendu obligatoire dans GitHub, la règle demande « une personne » et l'auteur compte, ou la fusion automatique est activée.

Autre point que les articles de lancement ne disent pas : le mode observation, celui qu'Anthropic recommande pour démarrer, est facturé. Et l'agent qui corrige n'a aucun plafond de dépense tant que vous ne l'avez pas posé.

Si j'avais une équipe de développeurs sur Claude Team lundi : un seul dépôt, un plafond mensuel, l'agent correcteur en mode manuel, la politique d'approbation en observation pendant deux semaines, et un développeur nommé pour comparer ses décisions avec celles des humains.

## IA pour un éditeur SaaS : Claude, ChatGPT ou Mistral, quel outil pour quelle tâche

- Page : `/blog/ia-editeur-saas`
- PR : voir la PR `feat/seo-2026-11-01`
- Brouillon : à relire et à publier par Simon

Dans un éditeur SaaS, la question n'est plus « ChatGPT ou Claude ». C'est « qu'est-ce que l'agent de code a le droit de faire dans mon dépôt ».

Les trois offres d'équipe que j'ai relues ce matin incluent un agent de code : Claude Code dans chaque siège Claude Team, Codex dans ChatGPT Business, Vibe en ligne de commande chez Mistral. De 20 à 25 $ HT par personne et par mois au siège de base.

Ce qui change d'un outil à l'autre, c'est ce qu'il fait sur GitHub. L'un corrige une pull request quand la CI échoue, l'autre relit une PR quand on le mentionne, le troisième annonce des agents qui ouvrent des PR.

Avant de choisir, je regarde trois choses chez mes clients : la branche principale est-elle protégée, les tests tournent-ils en CI, les secrets sont-ils sortis du code ? Si l'une des trois manque, l'agent ira plus vite dans le mur.

Et le code n'est pas la seule tâche : support, notes de version, spécifications, questionnaires de sécurité des clients. Là, une seule règle : l'assistant n'écrit que ce que vos documents disent.

## IA pour une ESN : Claude, ChatGPT ou Mistral, quel outil pour quelle tâche

- Page : `/blog/ia-esn`
- PR : voir la PR `feat/seo-2026-11-01`
- Brouillon : à relire et à publier par Simon

Dans une ESN, la première question sur l'IA n'est pas l'outil. C'est : à qui appartiennent les données qu'on met dedans ?

Le code et les documents d'un client relèvent de son contrat avec vous. Les CV relèvent des données personnelles de vos consultants. Ni l'un ni l'autre n'a sa place dans un compte gratuit ou personnel.

Les tâches où un assistant aide le plus sont internes : lire un appel d'offres, mettre un CV au format du client sans rien y ajouter, préparer une liste de profils pour un besoin, rédiger le compte rendu d'activité.

Sur le staffing, je préfère être clair : l'annexe III de l'AI Act classe à haut risque les outils de recrutement et ceux qui attribuent des tâches selon les caractéristiques des personnes, avec des règles applicables à partir du 2 décembre 2027. L'IA peut proposer une liste. Elle ne choisit pas qui part en mission.

Et pour les consultants en mission, ce n'est pas l'ESN qui choisit l'outil : c'est la politique du client.

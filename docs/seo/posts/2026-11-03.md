## Refonte de site et SEO : ne pas perdre son trafic, la liste de contrôle et le suivi mesuré

Page : `/blog/refonte-site-seo-sans-perdre-trafic` · PR : voir la PR `feat/seo-2026-11-03` · Brouillon : à relire et à publier par Simon.

J'ai refait mon propre site début octobre. Voici ce que Search Console m'a montré pendant quatre semaines.

Avant la refonte, le site n'avait presque pas de trafic : 16 clics en trois mois. Je ne vais donc pas vous dire que j'ai « sauvé » un trafic. Ce que je peux vous montrer, c'est comment l'indexation repart.

Le 4 octobre, 38 pages indexées sur 73. Le 1er novembre, 173 sur 255.

Ce qui m'a surpris : la position moyenne s'est dégradée, de 23,3 à 30,8, pendant que les impressions étaient multipliées par 40. Les pages nouvelles apparaissent d'abord loin, et elles tirent la moyenne. Après une refonte, la position moyenne du site ne vous dit rien. Regardez page par page.

Ce qui n'a pas marché : une page liée depuis l'accueil, toujours inconnue de Google quatre semaines plus tard. J'ai demandé l'indexation à la main.

Si vous refaites votre site, la question à poser à votre prestataire n'est pas « est-ce que vous faites les redirections ? ». C'est : « comment vous allez les tester, toutes, le jour de la mise en ligne ? »

## Claude Code, Codex ou Mistral Vibe : quel agent de code pour une PME

Page : `/ressources/comparatifs/claude-code-vs-codex-vs-vibe` · PR : voir la PR `feat/seo-2026-11-03` · Brouillon : à relire et à publier par Simon.

Claude Code, Codex ou Mistral Vibe ? Pour une PME, la qualité du code n'est pas la première question.

La première, c'est : lequel est déjà dans l'abonnement que vous payez. Claude Code est dans chaque siège Claude Team. Codex dans chaque siège ChatGPT Business. Mistral Vibe dans Vibe Team.

La deuxième, c'est où part votre code. Anthropic stocke les données aux États-Unis. OpenAI réserve l'hébergement en Europe à son offre Enterprise. Mistral héberge dans l'Union européenne par défaut.

Et puis il y a trois réglages que j'ai trouvés dans la documentation des éditeurs, et qu'aucun comparatif que j'ai lu ne mentionne :

1. Sur Vibe Team, l'entraînement sur vos échanges est actif tant que l'administrateur ne le coupe pas.
2. Chez Codex, une clé d'API rangée en variable d'environnement est lisible par l'agent. Il faut passer par les secrets réseau.
3. Chez Claude Code, l'accès aux dépôts se règle sur GitHub : une session voit tout ce que le compte GitHub connecté peut voir.

Ce sont des réglages de dix minutes. Faites-les le premier jour, pas après un incident.

Je n'ai pas fait de banc d'essai : la page compare ce qui décide l'achat, sources des éditeurs à l'appui, lues le 3 novembre.
